# 検索キーワードの方針（2026-10-11・日本時間）

## 選定

| 役割 | キーワード | 判断理由 |
| --- | --- | --- |
| TOPの主軸 | Web制作スクール | 企画・デザイン・コード・公開運用を学ぶ授業内容に合う |
| TOPの補助 | ホームページ作成／ホームページ制作 | 初学者にも学べる対象が伝わる |
| 既存の呼称 | HP制作専門スクール | ブランド表記として維持する |
| 授業内容の説明 | Webデザイン、HTML/CSS、JavaScript、CMS、SEO | 実際に学べる内容として自然に記載する |

「一番検索される語」「最も順位が上がる語」を特定したものではない。月間検索数、Search Consoleの検索語別実績、Googleでの地域・端末別順位は未取得。一般検索ツールの結果をGoogleの上位25件の再現として扱わない。

## 調査からわかったこと

「HP作成スクール」「Web制作スクール」「ホームページ作成スクール」「HP制作スクール」を検索した。制作を学ぶ講座のほか、スクール向けホームページ制作サービスも結果に混在するため、語句だけでなく学習内容と受講対象を明記する。

同種の学習内容を提供する一次情報として、次を確認した。競合が使う語句は検索ボリュームの証拠ではない。

- [デイトラ Web制作コース](https://daily-trial.com/web_site/)
- [アビバ Web制作プロフェッショナル講座](https://www.aviva.co.jp/course/creative/web_design/)

Googleは、読者が使う言葉を意識しつつ、あらゆる表記の組み合わせを網羅する必要はないと説明している。TOPには主軸と補助語を自然な文章で配置し、同義語を列挙しただけのページは作らない。

- [Google SEOスターターガイド](https://developers.google.com/search/docs/fundamentals/seo-starter-guide?hl=ja)

## 実装と確認範囲

TOPのtitle・description・OGP/X・WebPage構造化データ・H1・冒頭説明・FAQを調整。FAQの構造化データも表示本文と一致させた。ブランド名、料金、カリキュラム、受講条件は変更していない。

ローカルのTOPはindex指定、canonicalは https://school.junkbranding.com/ 、robots.txtはクロール許可、サイトマップにTOPを掲載済み。これはGoogleへの登録完了や上位表示を意味しない。

公開URLの取得はこの実行環境で名前解決に失敗し、検索ツールからの直接取得も失敗した。公開サイトの停止、Googlebotのアクセス不可、未登録と断定できない。site:検索でも当サイトの結果を確認できなかったが、インデックス状況の確定にはURL検査が必要。

## 公開後の確認

1. Search ConsoleのURL検査でTOPの登録状況、クロール可否、Googleが選択したcanonicalを確認する。未登録なら表示された原因を確認し、修正後に登録をリクエストする。
2. サイトマップの送信状況と取得結果を確認する。
3. 再クロール後に検索パフォーマンスを記録し、同じ期間幅で表示回数・クリック数・CTR・平均掲載順位を比較する。最初は28日単位を目安にし、表示回数が少なければ期間を延ばす。
4. 「Web制作」「ホームページ作成」「ホームページ制作」「HP作成」「HP制作」「Webデザイン」を含む検索語を確認し、実際に表示される語と問い合わせにつながる内容を基に調整する。

タイトル変更だけで検索掲載や順位は保証できない。未登録と、登録済みだが順位が低い状態を分けて判断する。
