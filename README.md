# 0→1 Web制作スクール 静的サイト一式

キャンバスで制作したデザインを、そのまま公開できる静的なHTML/CSS/JSに書き出したものです。

## 確認のしかた

### PageSpeed 改善（2026-10-08）

- 全26ページは `assets/css/generated/*.min.css` を読み込みます。`assets/css/` 直下のCSSが編集元で、`scripts/css-pages.json` に各ページで使うファイルと読み込み順を記録しています。HTML・CSS・JSを変更したら `npm ci`（初回）→ `npm run build` → `npm run check` を実行し、生成したCSSも公開してください。生成済みCSSを直接編集しないでください。
- ビルドではページのHTMLとフォームのJSから未使用セレクタを除外し、最小化します。動的な状態クラスは明示的にも保護しています。新しい動的クラスを文字列の結合で作る場合は `scripts/build-css.mjs` の `safelist` へ追加してください。新規ページは `scripts/css-pages.json` に追加してください。
- Google Fonts APIへのアクセスをなくし、`assets/fonts/` からフォントを配信します。768px以下では日本語を端末標準の書体で表示し、769px以上ではサイト内の文字に絞ったZen Kaku Gothic Newを使用します。英字はGeist / Geist Monoです。`font-display: optional` により、フォント取得が遅いときはフォールバックで表示を続けます。本文に新しい文字を追加したときの再生成手順・ライセンスは `assets/fonts/README.md` にあります。
- TOPの見出し・説明・CTAは、登場アニメーションを待たずに表示します。見出しのグラデーションの連続アニメーションも停止しています。
- canonicalは `https://school.junkbranding.com/` を維持します。Vercelの `vercel.json` に `/index.html` → `/` の恒久リダイレクトを設定しています。PageSpeedは `/` で再測定してください。
- 追加修正後、Lighthouse 13.5.0のローカル計測でモバイル100点（FCP/LCP 1.5秒、CLS 0）、PC99点を確認しました。同一ローカルサーバーで実回線スロットリングを適用した変更前後は62点→100点でした。記録は `reports/performance-2026-10-08.json` にあります。公開環境のPageSpeedスコアとは別の測定なので、公開後は `/` で再測定してください。

### HP制作専門スクールとしてのSEO（2026-10-07）

- 主な訴求は「ホームページ（HP）制作専門スクール」。既存のスクール名「0→1 Web制作スクール」は維持し、HP制作専門スクールを別名として構造化データにも記載しています。「日本唯一」「他にはない」など、調査範囲・時点を示せない比較表現は使用していません。
- TOPのH1、専門性を説明する本文、FAQ、各ページのtitle・description・OGP/Xのテキストを整備しています。企画・デザイン・実装・公開・運用という学習範囲を、カリキュラム・制作例・卒業制作へのリンクで示します。
- JSON-LDは、EducationalOrganization・WebSite・Course・WebPage・BreadcrumbList・Personを共通の`@id`で接続しています。組織とサイトの情報は全ページに記載し、講座情報はTOP・カリキュラム・受講料ページで統一しています。
- `python3 scripts/check_metadata.py`で全ページのメタ情報、JSON-LDの参照先・同一エンティティの整合性、FAQと表示本文の一致、H1、canonical、サイトマップを確認できます。料金や学習内容を更新したら再実行してください。
- 構造化データは検索エンジンへの内容説明です。順位やリッチリザルトの表示を保証するものではありません。[Googleの構造化データガイドライン](https://developers.google.com/search/docs/appearance/structured-data/sd-policies)に沿って、表示本文にある情報を記載します。
- FAQPageは本文の質問と回答を記述するために維持しています。GoogleのFAQリッチリザルトは2026年5月7日に表示を終了しています（[公式更新履歴](https://developers.google.com/search/updates#may-2026)）。また、このサイトは1講座のため、[コースリスト表示の3講座以上という条件](https://developers.google.com/search/docs/appearance/structured-data/course)を満たすための架空の講座は追加していません。
- 公開後はSearch Consoleでサイトマップを送信し、TOP・カリキュラム・受講料ページのURL検査を実施してください。「HP制作 スクール」「ホームページ制作 スクール」などの表示回数・クリック数・検索掲載順位を追い、実際の制作事例や講師の解説を継続して追加します。

`index.html` をブラウザで開けば見られます。スクロール連動のアニメーションやフォームを正しく確認するには、ローカルサーバーで開くのがおすすめです。

```
cd zero-to-one-site
python3 -m http.server 8000
# → http://localhost:8000 を開く
```

- スクロールに連動する演出は、Chrome / Edge / Safari 26 以降で動きます。非対応のブラウザでは、最初から完成した状態で表示されます。
- 「視差効果を減らす」設定の環境では、動きを止めて完成状態を表示します。
- フォントはサイト内から配信します（モバイルの日本語は端末標準の書体）。詳細は `assets/fonts/README.md` を参照してください。
- キーボード操作用に「本文へスキップ」リンクがあります（Tabキーで表示）。

## 公開前に差し替えるもの

### 必須
- **申し込みの流れ**：フォームの送信は「受講希望の受付」で、契約・決済はまだ成立しません。運営側で内容を確認したら、Stripeの決済ページ（Payment Linkなど）をメールで案内し、決済の完了で契約成立とする前提で、確認画面・特定商取引法の表記・利用規約を書いています。決済ページ側で、受講料・支払方法・提供時期・キャンセル条件を表示してください（特定商取引法の最終確認画面にあたります）。
- **受講契約の最終確認（confirm.html）**：フォームの内容を確認したあと、このページのURLをメールで送り、同意のチェックのあと Stripe の決済ページへ進む流れです。`<form id="cf-final" … data-payment-link="">` に Payment Link のURLを入れてください。Apps Script経由の場合は `data-checkout-endpoint` を設定します（詳しくは `STRIPE_INTEGRATION_TODO.md`）。表の `[ ]`（受講開始日・実費・質問とレビューの条件・キャンセル条件）も埋めてください。特定商取引法の「最終確認画面」にあたるページです。
- **面談予約**：お申し込みページで「面談を予約する」を選ぶと、2週間分の日付と時間の枠が表示されます。予約できるのは毎日19:00〜20:00・20:00〜21:00の2枠だけで、それ以外は「予定あり」と表示されます。factory0611@gmail.com のGoogleカレンダーと連動させる手順は `booking/README.md` にあります。
- **フォームの送信先**：`apply.html` の `<form id="ap-form" novalidate data-endpoint="">` の `data-endpoint` に送信先URLを入れてください。入力内容をJSONでPOSTします（Formspreeなどのフォームサービス、自社APIなど）。
  - **未設定のあいだは完了画面に進まず、「送信できませんでした」と表示**します（送信したふりはしません）。
  - 送信に成功したときだけ完了画面に進み、失敗したときはエラーを表示して再送信できます。
  - 確認メールの自動送信は、送信先のサービス側で設定してください。
- **URL**：全ページの `canonical`・OGP・JSON-LD・`sitemap.xml`・`robots.txt` は `https://school.junkbranding.com/` に設定済みです。下層ページは `.html` のURLで公開してください。契約確認・支払い後の案内は `noindex` のまま、サイトマップから除外しています。
- **OGP画像・ロゴ**：ルートの `ogp.png`（1200×630）と `logo.png`（512×512）も公開してください。再生成はmacOSで `swift scripts/generate-social-images.swift` を実行します。
- **運営者情報・特定商取引法に基づく表記・プライバシーポリシー**：運営者（JUNKBRANDING／木崎 有貴）・所在地・メールアドレス・創業年月は入力済みです。残りの `[ ]`（電話番号と受付時間、キャンセルと返金の条件、費用の扱い、委託先のサービス名、最終更新日など）を埋めてください。お申し込みの確認画面にも、受講料・支払い・受講開始・キャンセルの要点を表示しています（特定商取引法の最終確認画面の考え方に沿ったもの）。公開前に、専門家の確認を受けることをおすすめします。

### 決済
クレジットカード決済は **Stripe** を使う前提で、受講料ページ・特定商取引法に基づく表記・確認画面・プライバシーポリシーを書いています。日本発行のカードなら、Stripeの決済画面で分割払い・リボ払い・ボーナス払いを選べます（Stripeの設定で分割払いを有効にしてください）。対応ブランドは、ご契約内容に合わせて確認してください。

### 申込ページの表示方針
- 受講開始日は、決済前に受講契約の最終確認ページで案内します。`confirm.html` の具体的な開始日は、受講者に案内する前に確定して記載してください。
- 申込後・決済後の連絡は、内容・支払いを確認したうえでメールで行う旨を表示し、未確定の返信期限は表示しません。
- 募集月・残席数は表示せず、確定済みの定員「毎月2名まで」を表示します。

### 仮のまま入っている内容（[ ] で表示）
- 受講料は **398,000円（税込・クレジットカードの分割払い可）** で確定しています。変更する場合は「1カリキュラムあたり約12,438円」（32で割った金額）と、比較表・確認画面・特定商取引法の表記・構造化データの金額もあわせて直してください。
- FAQ・お支払いFAQの未回答項目（分割払い・支払い方法・返金・応募費用・卒業制作のテーマ など）

### 卒業制作サンプル（case.html）
卒業制作は講師がクライアント役を務める模擬案件で、サンプルの「パンと珈琲 こむぎのね」は**架空のお店**です。ページ内にも「模擬案件の例です」「実在のお店・受講生とは関係ありません」と明記しています。実際の卒業制作ができたら、本物の事例に差し替えるか、本物の事例を追加してください。サンプル内のドメインは、架空用に予約されている `.example` を使っています。

### 講師の写真と実名の取引先
- 講師の写真は、いま https://www.junkbranding.com/images/face.webp を直接読み込んでいます。表示速度と安定のため、画像ファイルを assets/img に置いて差し替えることをおすすめします。
- 講師の経歴に、取引先の実名（NTTラーニングシステムズ／OCN、Deckers Japan／Teva）が入っています。契約上、社名を出してよいか確認してください。出せない場合は「大手通信会社のポータルサイト」などの書き方に変えます。
- 経歴の2009年〜2019年が空いています。1行で埋めると、経歴を見る人の引っかかりがなくなります。

### 写真
**ストック写真は使っていません。**サイト内のビジュアル（KV・カード・各ジャンルのイメージなど）は、すべてHTMLとCSSで描いたオリジナルの図です。講師の写真は、写真ファイルをいただいたら差し替えます（いまは「木崎」の文字のアイコン）。

以前の版の説明：人物・仕事風景の写真は**仮素材**でした。MITライセンスのWebテンプレート（Start Bootstrap、Creative Tim）に同梱されていたUnsplash由来の写真を、色味をそろえて使っています。受講生の声や「1席目」には人物写真が入っていますが、**実在の受講生ではありません**。公開前に、撮影した写真や実際の作品に差し替えてください。

## 比較表（TOP）について

他社3社は匿名（A社・B社・C社）で、2026年10月4日時点の各社公式サイトの公開情報をもとに、**各社1コースずつ**で比べています。

- A社：Web制作コース（89,800円・教材は無期限で閲覧可・質問サポート1年間・課題レビューは中級・上級で1回ずつ）
- B社：パーソナライズコース（月額33,000円〜・月更新で推奨6ヶ月〜・個別設計のカリキュラム・1on1・合格するまで何度でもブラッシュアップ）
- C社：Webデザイナーコース（481,448円・受講期間の目安3〜4ヶ月・授業24回）

各社の料金はキャンペーンや改定で変わります（A社は以前129,800円でした）。公開直前に必ず各社の公式サイトで最新の内容を確認し、確認した日付を注記に反映してください。匿名比較のため、サイト上には各社へのリンクを載せていません（リンクを載せると社名がわかるため）。出典URL・確認日・確認状況は `data/competitors.json` にまとめています。確認のたびに、取得した画面のスクリーンショットも保存してください。**A社の料金は、確認する環境によって89,800円と129,800円の食い違いが出ているため、公開日に必ずブラウザで確認して確定してください。**匿名でも、価格などから社名が推測できる場合は、景品表示法上、実名での比較と同じく内容の正確さと根拠が求められます。
